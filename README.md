# Fuzzy Logic Assignment

## Overview

This project implements a **Fuzzy Logic System** as part of a university assignment. The system demonstrates the application of fuzzy logic principles to solve problems involving uncertainty and imprecision. It includes fuzzy sets, membership functions, fuzzy rules, and defuzzification methods to generate outputs based on fuzzy inputs.

## Features

* Definition of **fuzzy variables** and membership functions
* Implementation of **fuzzy inference rules** (IF-THEN rules)
* **Defuzzification** to convert fuzzy outputs into crisp results
* Demonstrates the workflow of a fuzzy logic control system

## Technologies Used

* **Python** for all computations and simulations
* **NumPy** for numerical calculations
* **Matplotlib** for plotting membership functions and results

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/McStupid/Fuzzy_Logic_assignment.git
   ```
2. Navigate to the project directory:

   ```bash
   cd Fuzzy_Logic_assignment
   ```
3. Run the main Python script:

   ```bash
   python fuzzy_logic.py
   ```
4. Observe outputs and plots of membership functions and final defuzzified results.

## Project Structure

* `fuzzy_logic.py` – Main script containing fuzzy logic implementation
* `README.md` – Project documentation
* `plots/` – Folder containing generated plots of membership functions and results

## Learning Outcomes

* Understand the concepts of **fuzzy sets and membership functions**
* Apply **fuzzy inference rules** to real-world problem scenarios
* Learn **defuzzification techniques** and how fuzzy systems produce actionable outputs
* Gain experience in **Python programming for control systems**
